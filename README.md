# TabletopGame - Nukkit-MOT 桌面游戏插件

## 项目简介

TabletopGame 是一个基于 Nukkit-MOT 服务器的桌面游戏插件，为 Minecraft 基岩版服务器提供五种经典桌面游戏：**五子棋 / 中国象棋 / 黑白棋（奥赛罗）/ 围棋 / UNO 牌桌**。插件通过自定义方块、实体、物品与内置资源包渲染出完整的 3D 棋盘与牌桌，玩家入座即可对战，支持机器人 AI、托管代打与 EconomyAPI 赌博结算。

资源包随插件打包，由服务端自动下发给客户端，无需手动安装。

## 功能特性

### 🎲 五大桌面游戏
- **五子棋**：2×2 与 3×3 两种棋盘规格（15×15 棋盘）
- **中国象棋**：标准 9×10 楚河汉界棋盘（32 子），内置 xqwlight 象棋引擎
- **黑白棋（奥赛罗）**：8×8 标准棋盘（64 格）
- **围棋**：9 路 / 13 路 / 19 路（19 路提供 3×3 与 4×4 两种摆放规格）
- **UNO 牌桌**：2~4 人对战，完整 UNO 规则（跳过 / 反转 / +2 / 野牌 / +4）

### 🤖 机器人系统
- 各棋均内置 AI：五子棋 / 黑白棋 / 围棋 / UNO 自研算法，象棋接入 xqwlight 引擎（入门 / 进阶 / 大师三档难度）
- AI 思考在异步线程执行，不阻塞服务端主线程
- UNO 支持一键补满人机、托管代打、断线自动接管

### 👥 多人对战
- 右键棋盘物品放置棋盘，按玩家视角确定摆放朝向，玩家入座开局
- UNO 牌桌支持定庄（四家同时抽牌比大小）、逐张发牌动画、45 秒出牌倒计时
- 出牌飞行动画、桌面方向箭头、庄家徽记、悬浮倒计时牌与结算展示板

### 💰 赌博系统
- 基于 EconomyAPI 的按倍数结算（倍数 k 由桌主设定，k=0 为免费局）
- 实扣 = min(手牌分 × k, 余额)，扣到零不出负数
- 奖池整体抽水（比例可配置），税后全额给赢家
- 开局余额门槛校验，余额不足无法开局

### 🔦 交互辅助
- **定位器**：UNO 牌桌持握道具，手持右键精准点选手牌 / 按钮，激光白点平贴牌面随准星移动
- 蹲下 + 使用键开关激光（动作栏提示）
- 所选格框 / 落点标记精确对齐棋盘网格线交点（黑白棋对齐格子中心）
- 离开棋盘范围自动退出棋局，菜单独占超时自动释放

### 💾 性能与持久化
- **单实体渲染**：象棋 32 子 / 奥赛罗 64 格 / 围棋整盘各由**一个**实体绘制，避免海量实体拖垮服务端
- **状态同步**：整盘落子状态按「行」编码进实体整数属性，一次批量同步给客户端
- 各棋盘独立存档文件（`plugins/TabletopGame/`），服务器重启后自动恢复棋局
- 配置实时生效，支持表单调整与文件重载

## 安装要求

### 必需前置
- **Nukkit-MOT** 服务器核心
- **EconomyAPI** - 经济系统插件（强依赖，缺失时插件拒绝加载）

### 环境要求

| 项目 | 要求 |
| --- | --- |
| 服务端 | Nukkit-MOT |
| Java | 17+ |
| 构建工具 | Maven（自行编译时需要） |

> 本插件在 `plugin.yml` 中以 `depend: [EconomyAPI]` 声明强依赖。未安装 EconomyAPI 时，Nukkit 会直接拒绝加载本插件，不会以「赌博不可用」的降级形态运行。

## 安装指南

### 1. 编译构建
```bash
mvn clean package
```

### 2. 安装插件
1. 将生成的 `TabletopGame-1.0.0-SNAPSHOT.jar` 放入 Nukkit 服务器的 `plugins` 目录
2. 启动服务器，插件将自动生成配置文件，并自动向客户端下发内置资源包
3. 基岩版客户端进服时**接受资源包**（棋盘 / 牌桌的模型与贴图都在资源包内，拒绝下载将看不到桌子）

> ⚠️ 资源包已内置在 jar 中（`assets/resource_pack`）。若更换过资源包内容，需同步升级 `manifest.json` 的版本号与双 UUID，客户端才会重新下载。

## 配置说明

### 完整配置文件 (config.yml)

```yaml
# TabletopGame 插件配置
# 推荐用 /tabletopgame settings 表单调整（OP，实时生效并自动保存）；手动编辑后可用 /tabletopgame reload 重载

# 玩家离开棋盘中心多少格后自动退出棋局（水平方向）
playerRange: 7.0

# 0 人入座时菜单的独占超时（秒）。超时或持有者下线会自动释放占用，让给其他人；有人入座后不再有该兜底
menuLockSeconds: 30

# UNO 牌桌物品是否可在工作台合成（默认 false = 不能合成，只能由 OP 用 /tabletopgame uno 发放）
# 开启后配方为（青色地毯 x3 / 深色橡木原木 x3 / 橡木板 x3）：
#   青色地毯     青色地毯     青色地毯
#   深色橡木原木 深色橡木原木 深色橡木原木
#   橡木板       橡木板       橡木板
unoTableCraftable: false

# 赌博模式设置（仅玩家对玩家对局生效；本插件强依赖 EconomyAPI）
gambling:
  # 官方每局抽水百分比（0~100，保留两位小数）。默认 1.0 即 1%；100 表示赢家也拿不到奖金
  cut: 1.0
  # 每局可下注的最小金额
  minBet: 1000.0
  # 每局可下注的最大金额
  maxBet: 1000000.0
  # UNO 牌桌开设「按倍数结算」对局（倍数 k > 0）时，每位真人玩家开局前必须拥有的最低余额。
  # 余额必须【大于等于】该值才能开局，否则提示「无法开局」。k = 0 的免费局不受此限制。
  minStartBalance: 10000.0
```

> **注意**: 推荐直接使用 `/tabletopgame settings` 表单调整（实时生效并自动保存）。手动编辑 `config.yml` 时多行注释必须保持 YAML 数组格式，格式错误会导致插件加载失败（插件会自动备份损坏文件为 `config.broken-<时间戳>.yml` 并重建默认配置）。

## 命令使用

### 主命令
```
/tabletopgame - 获得五子棋棋盘物品（默认 2×2）
```

### 发放棋盘 / 牌桌
```
/tabletopgame 3x3     - 3×3 五子棋棋盘
/tabletopgame xiangqi - 中国象棋棋盘
/tabletopgame othello - 黑白棋棋盘
/tabletopgame go9     - 围棋 9 路棋盘
/tabletopgame go13    - 围棋 13 路棋盘
/tabletopgame go19    - 围棋 19 路棋盘（3×3）
/tabletopgame go19big - 围棋 19 路棋盘（4×4）
/tabletopgame uno     - UNO 牌桌
```

### 管理员命令
```
/tabletopgame settings - 打开插件设置表单（OP，实时生效并写回 config.yml）
/tabletopgame reload   - 重载配置文件（OP 或控制台）
```

> 权限节点：`tabletopgame.command`（默认仅 OP）

## 物品说明

### 棋盘物品
- 用途：对准地面右键放置即生成棋盘
- 获取：`/tabletopgame` 系列命令（OP）

### UNO 牌桌 (UnoTableItem)
- 用途：右键地面放置 UNO 牌桌，入座后开设 UNO 对局
- 获取：`/tabletopgame uno` 或配置开启后工作台合成

### 定位器 (LocatorItem)
- 用途：UNO 牌桌的持握道具。手持它右键瞄准手牌 / 按钮，服务端通过射线判定点击目标，激光白点平贴牌面显示拾取位置
- 开关：蹲下 + 使用键切换激光（动作栏提示）
- 获取：入座 UNO 牌桌时自动发放，离桌自动回收

## 游戏玩法

### 棋类通用流程
1. OP 发放棋盘物品 → 玩家右键地面放置
2. 点击棋盘打开菜单 → 玩家入座（可补充人机）
3. 开局对弈，棋子实体自动落子，选中格框实时高亮
4. 对局结束自动结算，赌博模式下按配置扣款 / 发奖

### UNO 牌桌流程
1. 放置 UNO 牌桌 → 最多 4 人入座（人机可补位）
2. 桌主设定倍数 k（0 = 免费局）
3. 定庄：四家同时抽牌比大小，并列重抽
4. 逐张发牌动画（每人 7 张）→ 翻起始牌 → 顺时针轮流出牌
5. 手持定位器点击手牌出牌 / 抽牌，功能牌自动结算
6. 有人出完即结算：悬浮展示板显示各座位得分与金额变动

## 开发信息

### 技术栈
- **Nukkit-MOT** - 服务器核心
- **okaeri-configs** - 类型安全配置库（Nukkit-MOT 内置）
- **xqwlight** - 中国象棋搜索引擎
- **Maven** - 项目构建管理

### 项目结构

```
src/main/java/com/tabletopgame/
├── TabletopGamePlugin.java   # 插件入口（实体/方块/物品注册）
├── ai/                       # 各棋 AI 与象棋引擎（ai/xiangqi/、ai/xiangqi/pengjiu/）
├── board/                    # 棋盘/牌桌方块
├── command/                  # /tabletopgame 命令处理器
├── config/                   # 配置定义（okaeri-configs）
├── economy/                  # EconomyAPI 反射接入
├── entity/                   # 棋子/牌桌/载体实体
├── game/                     # 游戏逻辑（棋盘换算、Manager、UNO 牌桌状态机）
├── item/                     # 棋盘/牌桌/定位器物品与配方
├── storage/                  # 存档读写
└── ui/                       # 表单菜单
```

### 资源包
资源包内置于 jar（`assets/resource_pack`），包含棋盘 / 牌桌模型、动画、实体定义与贴图。客户端首次进服自动下载；修改资源后需升级 `manifest.json` 版本号并更换 header / module 双 UUID。
